# VILORD SCENE CUTTER — Android

Это нативный Android-проект на Kotlin. GitHub Actions настроен для облачной сборки установочного APK.

## Как получить APK с телефона

1. Создайте бесплатный аккаунт на GitHub и новый репозиторий (лучше Public, чтобы не упираться в лимиты приватных Actions).
2. Загрузите **всё содержимое этой папки проекта**, включая скрытую папку `.github/workflows/`, в корень репозитория. Не загружайте ZIP-файл вместо распакованных файлов.
3. Откройте вкладку **Actions** репозитория и выберите workflow **Build Android APK**.
4. Нажмите **Run workflow**. При первом запуске GitHub может попросить включить Actions.
5. Дождитесь зелёной отметки успешного завершения. Откройте завершённый запуск, прокрутите до **Artifacts** и скачайте **VILORD-SCENE-CUTTER-APK**.
6. Распакуйте скачанный ZIP на телефоне. Внутри будет `VILORD_SCENE_CUTTER.apk`. Откройте его и разрешите установку из этого источника, если Android спросит.

Также сборка автоматически запускается при push в ветки `main` или `master`.

## Что собирается

- APK типа **debug** (подходит для установки и проверки; не предназначен для публикации в Google Play).
- Имя файла: `VILORD_SCENE_CUTTER.apk`.
- SHA-256 контрольная сумма находится рядом в `SHA256SUMS.txt`.
- Артефакт хранится в GitHub Actions 30 дней.

## Требования к сборке

Workflow использует JDK 17, Android SDK и Gradle 8.9. Android Gradle Plugin 8.7.3 совместим с Gradle 8.9. Gradle Wrapper не требуется: runner устанавливает Gradle 8.9 в ходе workflow.

## Что реализовано в проекте

- Выбор видео через Android Storage Access Framework.
- Анализ смен сцен FFmpeg.
- Настройка порога и минимального расстояния между сменами.
- Ручное добавление диапазонов времени.
- Экспорт отдельных MP4-файлов с H.264 и AAC.

## Важные ограничения

- Сам APK в этот архив не включён: его создаст GitHub Actions после загрузки проекта в репозиторий и запуска workflow.
- В текущей среде нет Android SDK/Gradle, поэтому здесь невозможно подтвердить успешную компиляцию или установку на физический телефон. Если сборка завершится ошибкой, пришлите лог из вкладки Actions — исправлю причину.
- Большие видео требуют свободного места и времени на декодирование. Приложение пока не оформлено как foreground service; Android может остановить длительную обработку при сворачивании приложения.
- Используется `ffmpeg-kit-full-gpl`; проверьте требования GPL перед распространением приложения.
